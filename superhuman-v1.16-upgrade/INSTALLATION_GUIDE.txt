Refresh the page. Calendar now appears in navigation.

FIRST USE
- Open Review suggestions, then Collect meeting suggestions.
- This checks up to 100 completed inbox reports per click, from all four accounts.
  Repeat if the completion screen shows more reports waiting.
- Open a suggestion and inspect the linked source email excerpts.
- Verify the invitation, date, time and status. Edit the title and notes as needed.
  All editable dates and times are shown in Pakistan time (UTC+5).
- Add an end time if known; the app does not invent a meeting duration.
- Confirm to save a local meeting, or dismiss the suggestion.
- Meetings within 15 minutes of another start time get a duplicate/conflict hint.
  When it is the same meeting, link its source to the existing event. This keeps
  the existing event fields. Two separate meetings can start near the same time;
  only you decide whether they are duplicates.
- For rescheduling, edit the existing event first and then link the new source.
  For cancellation, cancel the existing local event and dismiss the suggestion.
- Open Add meeting for meetings missing from email reports.

READING THE CALENDAR
Upcoming shows confirmed future meetings and meetings with a known end time still
in progress. Tomorrow shows meetings starting on the next Pakistan calendar day.
Past and Cancelled are separate views. Event pages support edits, local cancellation,
source links and a single-meeting .ics download for manual calendar import.
Refreshing within an hour of a meeting shows a Starts within an hour badge.

IMPORTANT COVERAGE
Collection reuses explicit, timezone-aware meeting_at values already present in
completed structured inbox reports. It makes no extra model requests. It does not
read all emails again, parse calendar attachments, infer times from email delivery
or relative phrases, or query Google/Titan Calendar directly. Report items can omit
meetings, and excerpts can omit changes. Check your original invitation.

To discover new meetings: read inboxes in Briefing, request the next reports using
the existing displayed report budgets, wait for completion, then collect here.
If no suggestion appears, use Add meeting. Existing old-format reports without
structured meeting times cannot supply suggestions automatically.

Recurring meetings are individual occurrences; this version does not expand series.
Changes and cancellations need your review; email cannot silently update a meeting.
The tomorrow agenda and near-start badges are in-app reminders. This installation
does not provide push notifications or alerts while the page is closed.
Downloading or editing a local event does not send invitations or sync remote
calendars. Existing inbox access remains read-only.

ROLLBACK (ONLY IF NEEDED)
Keep the exact Rollback backup path printed by installation.
From the root server terminal:

systemctl stop superhuman-worker.service superhuman-web.service
sudo -iu superhuman
cd /home/superhuman/app

Replace BACKUP_DIRECTORY with the exact printed code backup path:

.venv/bin/python /home/superhuman/superhuman-v1.16-upgrade/install_v116.py --rollback BACKUP_DIRECTORY

Then return to root and restart:

exit
systemctl start superhuman-web.service superhuman-worker.service

Rollback restores v1.15 source and retains all saved data, including calendar
records. The calendar interface is unavailable on v1.15; reinstall v1.16 to access
those records again. Changed installed source or altered backups stop rollback.
