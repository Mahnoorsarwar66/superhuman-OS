# Interface and workflow decisions

The user asked to proceed with confirmed questionnaire answers and defer Q61–67. No user response, deadline, pilot amount, external authority or portrait likeness is invented.

Design guidance used: the available Sites skill's task-focused, responsive and accessible design guidance; Nielsen Norman Group's progressive disclosure and recognition-over-recall guidance; W3C WAI's multi-page forms, labels, instructions and grouped controls. No dedicated expert UI/UX skill was installed or claimed.

The main task is deciding what the team should produce and then inspecting its result. The interface makes that sequence visible: interview, saved brief, working plan, deliverable, evidence, approval and impact review. Five short interview views replace an opening wall of questions. A stable question catalogue adapts by department; agents may add bounded, project-scoped follow-ups during real work. This is not an autonomous interviewer running before the initial brief.

A light navigation rail and quiet green selection reduce contrast competition between navigation and work. Existing semantic navigation, native forms, fieldsets, legends, focus indicators and skip links remain. The current work state stays textual, not inferred from portraits. Portraits are fictional generated characters; The Twin is not a claimed likeness of Mahnoor.

Confirmation records expectation ownership. It does not verify company facts, certify source truth or approve externally consequential actions. Unknowns remain explicit. Newly saved answers hold enrolled project work and change review fingerprints, while merely proposed unanswered questions do not silently change confirmed scope.

The existing worker and accounting guard remain authoritative. Ready-milestone progression creates bounded assignments through existing start gates; it never approves predecessor packets. Existing projects require explicit enrolment. Outbound communications, channel permissions, independent reviewer method, exact deadline, pilot cap and workbook scope remain unresolved or unchanged as appropriate.

Historical packet impact reviews keep their original packet ID and digest. Costs include all attributable assignment attempts and new coordination links; historical unallocated costs remain disclosed. A user-entered time/rate range produces an estimated gross time value, not causal ROI or financial proof.

Native document exports convert only supported Markdown structures. The source text/packet remains authoritative. Unsupported tables retain every cell as text; typography and pagination need final human inspection for actual business deliverables.
