# Superhuman OS v1.26 — Persistent Team & Mahnoor Twin

Installation 1 of the agreed two-installation programme. Requires the v1.25 installation; this is an upgrade, not a complete application.

| Order | Release | Scope |
| --- | --- | --- |
| 1 — this package | v1.26 | Persistent internal team, Mahnoor Twin, writing skills, coordination, governance, scoped memory and USD accounting |
| 2 — subsequent package | v1.27 | Real communication connectors, cross-channel assistant intake and scheduled briefings, with action-specific permissions |

The team has eight persistent identities: Mahnoor Twin, EdSync Strategy / UK Innovator Endorsement, EdSync Product, Career Algorithm R&D, Sales & Marketing, Graduate Applications, Investors & Grants, and Legal & Operations. Each specialist has its own charter, tasks, memory, permissions and editable writing skill. Writer is no longer an independent employee. Old writing records remain accessible.

The Twin delegates and reviews routine internal work within your saved priorities. Specialists can request handoffs or challenge instructions; only you can approve an alternative over the Twin's instruction. Consequential, high-risk and restricted work requires your approval. Personal preferences proposed by the Twin require confirmation before becoming lasting memory.

Persistent means the service can resume saved work and react to changed work without keeping a chat window open. Eight identities share the existing worker; execution advances one step at a time. They are not eight continuously generating model processes. Two assignments may be active by default. Idle work does not cause continuous paid polling.

Read INSTALLATION_GUIDE.md before uploading. OPERATING_RULES.md explains setup and daily use; TESTING.md records validation and limits. No new Python dependency, server credential, Nginx setting or service unit is installed by this release.
