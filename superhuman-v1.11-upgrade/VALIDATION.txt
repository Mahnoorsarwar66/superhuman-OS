All model responses and research citations in tests are synthetic; no live
model API was called. Tests establish control flow and storage boundaries, not
model answer quality, reliability of task suggestions, or factual accuracy.

real Windows execution, real phone/browser interactions, live model latency/
provider-schema verification or independent security audit.
No user credentials, API keys, private SSH keys, conversations or databases are
included in this package. Installing and checking call no models. Sending a
message or approving a draft/research task uses the owner's existing API setup.
The server remains unchanged until the owner uploads and runs the upgrade.
